# Pastay

機密を AI に貼る直前に止める Mac のメニューバーアプリ

## 動く環境

- macOS 14 以降
- Apple シリコン搭載の Mac

## インストール

1. [Releases](https://github.com/shinonome-inc/pastay/releases/latest) から `Pastay.zip` をダウンロード
2. 展開した `Pastay.app` を「アプリケーション」フォルダに移して開く
