# Pastay

**AI に貼る前に、機密をチェック**

AI やチャットに貼る直前に、名前や電話番号、パスワードなどの機密を見つけてお知らせする Mac のメニューバーアプリ。<br>
チェックはすべて Mac の中で行います。

## できること

- **画面の上ですぐお知らせ** — 機密をコピーしたときや貼ろうとしたときに、画面の上（カメラのあたり）にお知らせが出ます
- **⌘V で止めて、伏せて貼る** — 貼り付けの瞬間に止めて、どうするかを選べます。「伏せて貼る」なら `[電話番号1]` のように置き換えて貼ります
- **警告の出し方を選べる** — 「知らせるだけ」か「止めて確認」かを、実際の表示を試してから選べます
- **コピーの履歴を安全に** — ショートカットで最大 1,000 件までさかのぼれます。履歴は暗号化して保存し、開くときは Touch ID で確認します
- **どのアプリでも** — ChatGPT・Claude・Gemini などの AI はもちろん、Slack やメールに貼るときも見張ります

## 安心して使えるように

- **内容は送らない** — コピーした文章もチェックの結果も、外に送ることはありません。チェックに使う AI も Mac の中で動きます
- **履歴は暗号化** — 履歴は暗号化して Mac の中に保存し、鍵はキーチェーンに保管します
- **入力は記録しない** — アクセシビリティの許可は、⌘V に気づくためだけに使います

サービス改善のため、起動回数などの利用状況の統計だけを送ります。

## 動く環境

- macOS 14 以降
- Apple シリコン（M1 以降）搭載の Mac
- AI でのチェックには、Apple Intelligence を有効にするか、設定画面からチェック用のモデルをダウンロードします

## インストール

1. [Pastay.dmg](https://github.com/shinonome-inc/pastay/releases/latest/download/Pastay.dmg) をダウンロード（[Releases](https://github.com/shinonome-inc/pastay/releases/latest) からも取れます）
2. 開いた窓で、`Pastay` を `Applications` にドラッグする
3. 「アプリケーション」フォルダから `Pastay` を開き、案内に沿って警告の出し方を選ぶ

アップデートは、アプリが自動で確かめます（設定の「アップデート」）。
